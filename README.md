# Проект: Прогнозирование стоимости страховых выплат

## Описание проекта

Страхование работников является важным инструментом социальной защиты сотрудников. 
Страховые компании сталкиваются с необходимостью точной оценки защиты сотрудников. 
Страховые компании сталкиваются с необходимостью точной оценки будущих выплат по страховым случаям.

## Цель проекта
Цель проекта — разработать модель машинного обучения для предсказания итоговой стоимости страхового возмещения (UltimateIncurredClaimCost) на основе характеристик работника и параметров случая.

## Датасет
Используется датасет **Workers Compensation** (ID: 42876), содержащий 100,000 записей о страховых случаях.
